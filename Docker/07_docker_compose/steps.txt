1. create a file with exact this name Dockerfile  (no extension)
2. prepare the config file 
3. run this command to build you're image :- docker build -t first-docker-img (-t means tag you're img name)
4. run the image by typing  : docker run -it -p <local-port>:<container-port> <image-name> (open browser and type : http://localhost:<local-port>);

5. open free account on hub.docker.com 
6. run : docker login on terminal 
7. create a repo and give a name to it (i gave a name called : my-first-node-app)
8. create a tag with you're image and repo name : docker tag my-node-app:latest varunmendre04/my-first-node-app:latest
9. Verify -> docker images
10. docker push varunmendre04/my-first-node-app:latest
